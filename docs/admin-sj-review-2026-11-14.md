Review 14 November 2026: Admin SJ dan pembaruan kurir

Halaman online https://on-track-indol.vercel.app/ beserta `/kurir`, `/js/app.js`, dan `/js/sj_import_engine.js` dibaca langsung tanpa login atau penulisan database. Keempat respons cocok byte demi byte dengan berkas `public/` pada commit `c012785` (Add customer Admin SJ import and courier sync). Workspace mengandung perubahan lokal lain; hasil tes seluruh workspace tidak otomatis membuktikan versi online bebas bug.

Temuan berdasarkan kode deploy aktif:

1. **Prioritas tinggi — customer dengan beberapa Admin SJ ditimpa diam-diam.** `public/js/app.js`, `importClientsFromExcel`: `importedByName.set` memakai satu entri per normalisasi nama; setiap baris berikutnya mengganti admin sebelumnya. Excel ADMIN SJ.xlsx berisi 17.041 baris bernama, 735 kunci customer unik, dan 202 kunci dengan lebih dari satu admin. Contoh PT HOME CENTER INDONESIA RETAIL memiliki ELIN, FIFIH, NOVA, SULIS. Urutan baris bukan bukti siapa PIC aktif. Daftar konflik tersedia di `.artifacts/admin-sj-review-2026-11-14/customer-admin-conflicts.csv`. Perlu aturan bisnis untuk satu PIC aktif atau beberapa PIC; konflik sebaiknya ditampilkan sebelum master disimpan.

2. **Prioritas tinggi — import mengaku berhasil ketika penyimpanan cloud ditolak.** `public/js/sj_import_engine.js:1724`: kegagalan `batch.commit()` ditangkap, lalu kode menambahkan SJ ke localStorage dan memori serta menampilkan pesan berhasil. Variabel `savedToCloud` tidak diperiksa lagi. Simulasi `permission-denied` terhadap JavaScript yang diunduh dari deploy berhasil mereproduksi kondisi ini. Akibatnya dashboard komputer admin dapat terlihat benar sementara perangkat kurir tidak menerima SJ tersebut. Perilaku ini sudah ada sebelum commit Admin SJ; tetap aktif pada deploy sekarang. Jangan menyamakan penyimpanan browser dengan berhasil tersinkron ke kurir.

3. **Prioritas sedang — koreksi Admin SJ pada preview hilang setelah pencarian.** `public/js/sj_import_engine.js:1494`: filter merender ulang dari `currentPreviewRows`, sedangkan edit input hanya dibaca saat commit. Mengubah ELIN menjadi FIFIH lalu mengetik pencarian mengembalikan ELIN. Simulasi kode deploy mereproduksi masalah. Perubahan harus disimpan ke model preview saat input berubah, termasuk ketika baris disembunyikan filter.

4. **Prioritas sedang — kolom “Admin Surat Jalan” salah dibaca importer SJ.** `public/js/sj_import_engine.js:111`: aturan umum `surat jalan` mendahului aturan admin, dan deteksi formulir cetak juga terlalu luas. Tabel sederhana dengan No SJ=SJ-1 dan Admin Surat Jalan=ELIN menghasilkan nomor SJ `1` dan admin kosong pada simulasi deploy. Kolom `Admin SJ` standar berhasil pada jalur yang diuji. Perbaikan perlu mencakup urutan pemetaan header dan deteksi layout agar tabel tidak berubah menjadi formulir cetak.

5. **Prioritas sedang — dispatch manual dari database customer membuang Admin SJ.** `public/js/app.js`, `addSelectedClients` dan `submitTrip`: data checkbox customer, antrean, dan payload destinasi tidak meneruskan `adminSJ`. Simulasi fungsi deploy memastikan antrean tidak membawa field tersebut. Jalur import Excel SJ sudah menyimpan admin pada root dan destinasi; jalur manual belum konsisten.

6. **Prioritas sedang — dashboard dan kurir memakai prioritas admin berbeda.** Dashboard dan export memilih `t.adminSJ || d.adminSJ`; kurir memilih `dest.adminSJ || t.adminSJ`. Jika root dan destinasi berbeda, dua layar menampilkan PIC berbeda. Kasus baru satu SJ/satu tujuan biasanya memiliki kedua nilai sama, sehingga bug ini laten sampai ada edit atau rute gabungan dengan nilai berbeda. Gunakan prioritas destinasi secara konsisten.

7. **Prioritas sedang — cache master customer dapat tertinggal pada tab lain.** `getCustomerAdminSJLookup` memakai `cachedAllClients` tanpa refresh selama cache sudah terisi. Update master dari PC/tab lain tidak diambil oleh import berikutnya pada tab itu, kecuali pengguna masuk menu customer atau reload. Perlu pembaruan cache atau pengambilan master terbaru sebelum preview import.

Pembaruan APK:

Source `MainActivity.kt:263` memuat `https://on-track-indol.vercel.app/kurir.html`; fitur HTML/JavaScript online dapat diperbarui tanpa membangun APK baru untuk aplikasi yang menjalankan loader ini. Respons kurir online memakai `cache-control: public, max-age=0, must-revalidate`. Source tidak memiliki `onResume` untuk reload dan halaman kurir tidak mempunyai mekanisme pemeriksaan versi/visibilitychange. Jadi kembali dari background tidak menjamin kode baru dimuat. `onReceivedError` beralih ke `file:///android_asset/kurir.html` tanpa mekanisme kembali otomatis ketika internet pulih. Refresh halaman file tetap memakai aset bawaan. APK yang benar-benar terpasang di ponsel belum diidentifikasi atau diuji; kesimpulan loader ini berasal dari source yang tersedia, bukan verifikasi binary terpasang. Perubahan native memerlukan update APK; perubahan UI web dapat dilakukan melalui deploy. Mekanisme pembaruan sebaiknya mendeteksi versi baru dan menunggu laporan/foto selesai sebelum reload agar input kurir tidak hilang.

Master Bahan tetap mengikuti tahap lokal: HTML deploy yang diperiksa tidak memuat modul `material_master`, `material_seed`, atau `material_usage`; dashboard lokal memuatnya. Review ini tidak memublikasikan fitur bahan.

Verifikasi: 153/153 tes workspace lulus setelah izin port localhost tersedia. Empat simulasi tambahan pada JavaScript hasil unduhan deploy mereproduksi temuan 2–5. Analisis XML Excel menghasilkan jumlah konflik pada temuan 1. Tidak ada login kurir, pengubahan Firestore, deploy, atau build APK dalam review ini. Server localhost:3000 yang sudah berjalan merespons dengan runtime sandbox lokal. Tidak ada perbaikan implementasi diterapkan pada tahap review.
