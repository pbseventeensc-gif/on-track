Pembukaan menu Customer memakai data yang sudah tersedia di memori atau cache tampilan per UID. Satu listener Firebase memperbarui daftar di latar belakang; membuka ulang menu tidak menjalankan GET seluruh customer lagi. Cache berumur maksimal tujuh hari dan tidak dipakai sebagai pengganti pemeriksaan server saat import atau simpan. Logout/pergantian akun menghentikan listener lama dan mengabaikan respons dari sesi sebelumnya. Tombol Muat ulang tetap mengambil data server secara eksplisit. Data pencarian diindeks dan diurutkan ketika daftar berubah, bukan pada setiap render.

Tombol Admin SJ di header membuka daftar nama dan form tambah admin. Nama baru disimpan secara terpisah di collection `sj_admins`, dengan ID berdasarkan nama yang dinormalisasi dan transaksi untuk mencegah duplikat. Admin yang belum ditugaskan ke customer tetap tersedia setelah refresh. Nama yang masih digunakan pada customer juga tersedia di pilihan. Sandbox memakai master lokal `wtrack_local_sj_admins_v1`, terpisah dari Firebase.

Kolom Aksi dipindah ke sebelah Admin SJ, sebelum Alamat. Ikon pensil membuka editor customer; ikon orang-plus membuka pilihan Admin SJ untuk satu customer dengan nama customer dan jumlah target yang jelas. Pilihan massal seluruh hasil pencarian tetap tersedia. Memilih nama admin baru pada pengisian customer juga menyimpannya ke daftar admin.

Validasi: 177 tes lulus. Tes mencakup cache tampilan yang tidak menggantikan lookup server, listener tunggal, pergantian akun, error jaringan, penambahan admin tanpa customer, duplikat nama, serta pembacaan daftar yang terlambat setelah admin baru disimpan. Uji browser memeriksa penambahan admin, ikon satu customer, penyimpanan setelah refresh, posisi Aksi dan dialog pencarian. Pada harness browser dengan 3.182 customer dan respons server yang sengaja ditunda, cache tampil sekitar 34 ms; sepuluh pembukaan ulang memerlukan sekitar 3,3 ms tanpa GET koleksi ulang. Angka ini mengukur render cache pada mesin uji, bukan waktu unduhan awal Firebase atau jaminan waktu pada semua perangkat. Pembukaan pertama tanpa cache tetap memerlukan koneksi Firebase.
